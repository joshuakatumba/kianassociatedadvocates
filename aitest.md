
1. Design and UI: 30 Reasons Your Site Looks "Vibecoded" (AI-Generated)

1. Harsh gradients: Over-saturated, unrefined color transitions.
2. Lucide icons: Default icon pack found on most basic AI templates.
3. Pure white backgrounds: Flat white (#ffffff) without visual hierarchy or
    subtle tinting.
4. Rainbow coloring: Random, uncoordinated multi-color accents.
5. Drop shadows: Heavy, un-diffused box shadows across all elements.
6. Three feature cards in a row: The repetitive generic layout.
7. Mobile OS emojis: Using stock emojis in place of proper UI icons.
8. Liquid glass effect: Overdone frosted glass and glassmorphism styling.
9. Em dashes: Overused AI copywriting formatting.
10. Default fonts: Uncustomized use of Inter, Geist, or Space Grotesk.
11. Left colored border stripes: Generic colored vertical accent bars on cards.
12. Fake testimonials: Placeholder personas with generic praise.
13. Bento grids: Forced grid layouts that do not fit the content.
14. Fake terminal windows: Code and command-line mockups where unnecessary.
15. Cliché copy: Lines like "It is not X, it is Y" or "Built different".
16. Checkmark bullet lists: Repetitive, generic feature lists.
17. Standard pricing tiers: Default Free / Pro / Enterprise structure without
    custom packaging.
18. Missing real product demos: Abstract cards with no actual screenshots or UI
    views.
19. Excessively soft corner radius: Over-rounded buttons and containers.
20. Purple and black palette: The standard AI SaaS color scheme.
21. Missing skeleton loaders: Abrupt layout shifts instead of smooth loading
    states.
22. Radial background orbs: Generic glowing gradient blur circles.
23. Dot grids: Default background dot matrix patterns.
24. Sparkle icons: Overused star/sparkle indicator on all AI features.
25. Animated arrows: Excessive looping bounce or pulse arrows.
26. Missing Terms of Service (TOS).
27. Missing Privacy Policy.
28. Excessive hover animations: Jittery, unoptimized hover states on every
    element.
29. Neon over-saturation: Unbalanced glowing neon accent colors.
30. Basic pastel palettes: Washed-out, generic pastel backgrounds.

5. SEO and Performance Checklist

Technical and On-Page SEO

  - Fix all indexing and crawlability issues in Google Search Console.
  - Add breadcrumb navigation for clear site hierarchy.
  - Implement canonical tags to prevent duplicate content issues.
  - Optimize Core Web Vitals (LCP, FID/INP, CLS).
  - Find and fix orphan pages (pages lacking internal links).
  - Implement structured Schema markup (Organization, FAQ, Product, etc.).
  - Establish proper heading hierarchy (single H1, logical H2 and H3 tags).
  - Fix all broken links and resolve 404 status codes.
  - Ensure client-side JavaScript content is fully crawlable by search bots.
  - Identify and resolve keyword cannibalization across competing pages.
  - Ensure page titles remain between 50 and 60 characters.
  - Write unique meta descriptions between 120 and 160 characters.
  - Merge thin, low-value, or overlapping pages.
  - Add descriptive alt text to all images.
  - Use clean, short, descriptive URL slugs.
  - Build strategic internal links to high-priority landing pages.

Content Strategy and E-E-A-T

  - Write original, comprehensive content.
  - Avoid duplicate or scraped content.
  - Match every page's structure and depth to user search intent.
  - Target high-volume, low-keyword-difficulty (KD) queries.
  - Add clear author bios, credentials, and experience signals.
  - Acquire high-quality, relevant external backlinks.
